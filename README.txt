MAHADEV ENTERPRISE — STARTER WEBSITE

WHAT THIS IS
- Responsive Orange + White storefront starter.
- Sections for second-hand phones, mobile accessories, repair services, shop pickup, opening hours, directions, WhatsApp contact, cart and WhatsApp order-enquiry message.
- Demo products/prices are placeholders. Replace them before showing customers.
- Illustrative product icons are not photos of actual stock.

IMPORTANT LIMITATIONS — NOT READY FOR LIVE ORDERS
This is a front-end starter, not a deployed production e-commerce system.
It does NOT yet have:
- Secure admin login or admin ID/password
- Customer SMS OTP authentication
- Database-backed products, stock or orders
- Automatic order notifications/storage
- Online UPI/payment processing
- Server-side validation, privacy policy, terms, or security configuration

Do not advertise the demo prices as actual offers. Checkout opens WhatsApp with an order enquiry only; no payment is taken and no order is saved to a database.
